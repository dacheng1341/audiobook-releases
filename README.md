## 核心技术特性

- **🎙️ 微软 Edge PVE 网络超清神经语音**：内置专属云阳（播音男声）、晓晓（生动女声）等顶级神经语音，真人生动连读，离线自动无缝降级。
- **✍️ iPad 原生级手写与智能图形吸附**：基于不可变基准视口数学模型，任意缩放笔迹零偏移；末端停顿 400ms 智能识别标准直线、箭头、矩形、椭圆。
- **👥 多人员图层合流与师生在线批改**：多人员笔记同屏分层切换，老师批改层与学生作答底稿物理隔离。
- **⚡ 局域网极速互传与本地优先数据安全**：所有图书与笔迹保存在本地设备（IndexedDB），同一 Wi-Fi 免流量秒传。
