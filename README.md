- **🎙️ 微软 Edge PVE 网络超清神经语音**：内置专属云阳（播音男声）、晓晓（生动女声）等顶级神经语音，真人生动连读，离线自动无缝降级。

- **👥 多人员图层合流与师生在线批改**：多人员笔记同屏分层切换，老师批改层与学生作答底稿物理隔离。
